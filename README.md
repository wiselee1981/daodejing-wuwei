# ☯ 无为而治 · 道德经互动课堂

一个用**交互式动画**讲解《道德经》「无为而治」知识点的响应式网站——水墨宣纸风格，桌面 / 平板 / 手机均可流畅浏览，目标是让零基础的读者也能一步步看懂。

## 🎓 课程内容（10 步）

| 步骤 | 主题 | 互动方式 |
|---|---|---|
| 序 | 老子是谁？书讲什么？ | 三问展开卡 + 生平时间轴 |
| 壹 | 破误区：无为 ≠ 躺平 | 翻转三张误区卡片 |
| 贰 | 治大国，若烹小鲜 | 亲手「煎鱼」：翻烂 vs 静候 |
| 叁 | 庖丁解牛 | 顺纹理切 vs 硬砍骨头动画 |
| 肆 | 大禹治水 | 鲧「堵」vs 禹「疏」动画演示 |
| 伍 | 文景之治 | 拖动「折腾指数」滑杆看国运变化 |
| 陆 | 萧规曹随 | 8 幕点击推进小剧场 |
| 柒 | 四句金句 | 翻转卡背白话翻译 |
| 捌 | 现代应用 | 工作 / 教育 / 生活场景切换 |
| 玖 | 小测验 | 8 题即时判分 + 等级徽章 + 错题回顾 |

## ✨ 特色功能

- 🔦 **深色模式**：自动跟随系统，也可手动切换并记忆偏好
- 🔊 **章节朗读**：每章「听讲解」按钮，浏览器原生语音朗读要点
- 📱 响应式：桌面 / 平板 / 手机布局自适应，触控热区 ≥ 40px
- ♿ 无障碍：语义化结构、键盘可操作、`prefers-reduced-motion` 适配

## 📚 内容依据

知识点经联网检索并交叉核对，主要参考：

- 人民日报《「治大国若烹小鲜」今解》（韩非子《解老》、河上公注、《毛诗故训传》等权威注疏）
- 澎湃新闻《缓慢的改革：「文景之治」中的「无为」实则大有为》
- 维基百科：文景之治 / 萧规曹随（含《史记·曹相国世家》原文）/ 鲧禹治水 / 老子
- 中国哲学书电子化计划：司马迁《史记·老子韩非列传》、庄子《养生主·庖丁解牛》原文

原文出处均标注章号：《道德经》第 2、17、37、57、60、63、64 章；《庄子·养生主》；《史记·曹相国世家》等。

## 🚀 本地运行

纯静态站点，无需构建：

```bash
# 任选其一
python3 -m http.server 4173 --directory .
# 或直接双击 index.html
```
