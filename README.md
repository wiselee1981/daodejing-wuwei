# ☯ 无为而治 · 道德经互动课堂

一个用**交互式动画**讲解《道德经》「无为而治」知识点的响应式网站——水墨宣纸风格，桌面 / 平板 / 手机均可流畅浏览，目标是让零基础的读者也能一步步看懂。

## 🎓 课程内容（8 步）

| 步骤 | 主题 | 互动方式 |
|---|---|---|
| 壹 | 破误区：无为 ≠ 躺平 | 翻转三张误区卡片 |
| 贰 | 治大国，若烹小鲜 | 亲手「煎鱼」：翻烂 vs 静候 |
| 叁 | 大禹治水 | 鲧「堵」vs 禹「疏」动画演示 |
| 肆 | 文景之治 | 拖动「折腾指数」滑杆看国运变化 |
| 伍 | 萧规曹随 | 8 幕点击推进小剧场 |
| 陆 | 四句金句 | 翻转卡背白话翻译 |
| 柒 | 现代应用 | 工作 / 教育 / 生活场景切换 |
| 捌 | 小测验 | 4 题即时判分 |

## 📚 内容依据

知识点经联网检索并交叉核对，主要参考：

- 人民日报《「治大国若烹小鲜」今解》（韩非子《解老》、河上公注、《毛诗故训传》等权威注疏）
- 澎湃新闻《缓慢的改革：「文景之治」中的「无为」实则大有为》
- 维基百科：文景之治 / 萧规曹随（含《史记·曹相国世家》原文）/ 鲧禹治水

原文出处均标注章号：《道德经》第 2、17、37、57、60、63、64 章等。

## 🚀 本地运行

纯静态站点，无需构建：

```bash
# 任选其一
python3 -m http.server 4173 --directory .
# 或直接双击 index.html
```
